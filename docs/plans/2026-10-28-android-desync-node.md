# Spec: узел обхода DPI (SNI / DESYNC) в Nova Android

> Статус: черновик, требует подтверждения владельца. Дата: 2026-10-28.
> Репозиторий: `Nova-Android-Fork`, ветка `personal`, версия 1.34.0.

## Objective

Добавить в приложение отдельный узел связи (транспорт), который обходит DPI
средствами самого приложения, без root и без системных модулей. Узел должен:

- быть отдельной кнопкой на главном экране (dock) и отдельным разделом настроек;
- работать на нерутованном Android через `VpnService` + локальный прокси;
- применять к исходящим TLS-соединениям методы, аналогичные zapret/ByeDPI:
  фрагментация ClientHello, разнесение TLS-записей, паддинг SNI, decoy-соединение;
- не затрагивать облачные профили, существующие транспорты и их настройки.

Успех MVP: узел поднимается, HTTPS-трафик идёт, фрагментация реально применяется
(подтверждается логом и тестом), при отключении узел не оставляет процессов и
правил. Работоспособность против конкретного DPI проверяется живыми пробами.

## Feasibility (без root)

| Метод zapret/ByeDPI | Без root | Как реализуем |
|---|---|---|
| split / disorder ClientHello | да | пользовательский TCP-стек/прокси: несколько `write()` с паузами, малый MSS |
| TLS record fragmentation | да | разбиение записи на несколько TLS-записей |
| SNI padding | **нет** | вставка байтов меняет transcript: TLS-клиент отвергает ответ (SEC_E_MESSAGE_ALTERED). Только в decoy-пакете |
| fake ClientHello с чужим seq | **нет** | нужен raw socket (root). Спайк: decoy на отдельном TCP-соединении |
| TTL-трюк | частично | `IP_TTL` на своём сокете виден только для decoy-соединения |
| nfqueue/WinDivert-подмена | **нет** | в Android без root недоступно |

Вывод: честно реализуем «split/фрагментация + decoy», а не полный zapret.
Этот узел не обещает работать против DPI, который смотрит на перекрытие
TCP-сегментов; для таких сетей остаются WARP/MASQUE/VLESS.

## Архитектура

```
VpnService (tun)
   └── tun2proxy ── SOCKS5 ── nova-desync (Go, дочерний процесс)
                                 ├── TLS-aware splitter (443)
                                 ├── passthrough (остальные порты)
                                 └── decoy-соединение (опция)
```

- Новый Go-бинарник `nova-desync` (arm64-v8a, armeabi-v7a), стиль запуска —
  как `opera-proxy`: процесс, локальный порт, pid-файл, лог, мягкая остановка.
- Порт: 1376 (свободен; 1369–1380 заняты PC-форком, на Android проверить).
- DNS: существующий `LocalDnsProxyManager`, без изменений.
- QUIC/UDP: блокируется на маршруте узла, чтобы браузер шёл по TCP и попадал
  под фрагментацию (иначе обход не применяется).

## UI

- Dock: восьмая иконка `SNI` (или `DESYNC` — см. открытые вопросы), SVG
  `ic_node_desync`, порядок — в конец `ConnectionSelectorPolicy.ORDER`.
- Настройки: раздел «Обход DPI» — методы (split 2/3 части, пауза, паддинг,
  decoy), порт, кнопка «Проверить» (тест к известному HTTPS).
- Строка под селектором: предупреждение, что узел помогает не во всех сетях.

## Testing Strategy

- Go: unit-тесты сплиттера (границы TLS-записи, паузы, паддинг), интеграционный
  тест с локальным TLS-сервером, проверка, что ClientHello приходит фрагментами.
- Kotlin: тесты политики (новый узел в ORDER/ROWS/доступности), запуск/останов
  процесса, отсутствие утечек pid.
- Живые пробы: 2–3 сети, `curl` через локальный порт, сравнение с прямым каналом.
- Эмулятор x86 не подходит для ARM-бинаря; нужен USB-девайс.

## Boundaries

- Always: не трогать `ProtonProfileManager`, `VlessSubscription*`,
  `WarpProfileGenerator`, `Gateway*`; новые файлы — отдельно; фича за флагом.
- Ask first: добавление Go-модуля/бинаря в APK (+2–4 МБ на ABI), изменение
  `ConnectionSelectorPolicy` (позиционный разбор в настройках), новые разрешения.
- Never: root, magisk, системные правила, изменение applicationId/подписи.

## Success Criteria

1. В dock есть отдельная кнопка, выбор сохраняется, остальные транспорты не ломаются.
2. `nova-desync` поднимается и принимает SOCKS5, HTTPS работает через узел.
3. В логе видно, что ClientHello ушёл ≥2 фрагментами; тест подтверждает.
4. Останов VPN завершает процесс и не оставляет слушателей.
5. Release собирается, размер APK растёт не более чем на ~4 МБ на ABI.

## Решения (согласовано 2026-10-28)

1. Подпись узла — **DESYNC**.
2. Режим — **самостоятельный прямой канал** (без upstream VPN).
3. MVP — split ClientHello и разбиение на TLS-записи, **decoy остаётся
   включённым** (требование владельца, несмотря на оценку моделей).
   Паддинг настоящего ClientHello **исключён**: проверка на живом curl показала
   `SEC_E_MESSAGE_ALTERED` — прокси не может менять байты рукопожатия, не
   становясь MITM.
4. **QUIC блокируется** в этом узле, но переключателем (по умолчанию включён).
