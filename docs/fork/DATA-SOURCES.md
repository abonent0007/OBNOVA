# Внешние источники и статические данные

> Инвентаризация на 2026-11-04. Единая точка для адресов лент —
> `ExternalSources.kt`; загрузка — `FeedHttp.kt` (тайм-ауты, проверка HTTP-кода,
> потолок тела). Ниже — что обновляется само, что остаётся запасным вариантом и
> почему.

## Динамические источники

| Данные | Код | Лента | Периодичность | Запасной путь |
|---|---|---|---|---|
| Списки доменов маршрутизации | `ListSync` | `nova_updates/nova_pc/manifest.json` + sha256, 3 зеркала | по кнопке/фону | прошлая локальная копия, затем `assets/lists/*` |
| IP-списки Cloudflare/YouTube/Telegram | `ListSync` (`IP_ASSETS`), `ListRepository.cidrs` | `nova_pc/ip/*.txt` из манифеста | вместе со списками | прошлые `*_ips.txt`, затем `assets/ip/*` |
| Сервер DNS-туннеля Nova | `DnsServerFeed` | `nova_android/dns_tunnel.json`, raw + Pages | 8 ч и при подключении | `SEED` в коде и прошлое состояние в файле |
| Адреса Opera | `OperaEndpointFeed` | `opera_endpoints.json`, raw + Pages | 3 ч / перед запуском | кэш `discover`, затем собственный discover |
| Версия APK | `AppUpdateManager` | GitHub Releases API **`abonent0007/OBNOVA`** (не upstream) | периодически (в форке выключено) | нет: приватный репозиторий без токена отвечает 404 → ручное обновление |
| Мосты Tor | `TorBridges` | OnionHop (4 зеркала) + Delta (2), MOAT | при запросе | встроенные мосты и прошлый файл |
| Конфигурации WARP по умолчанию | `WarpConfigsActivity` | `confeden/auto-warp-config` | по кнопке | уже импортированные конфиги |
| VLESS-подписка | `RoutesActivity` | `iboxz/free-v2ray-collector` | по кнопке | нет: это seed, не гарантия живых узлов |
| Proton API | `ProtonApi` | `vpn-api.proton.me`, `api.protonvpn.ch` | при подключении | второй хост, pinned DoH |
| WARP API | `WarpClient` | `api.cloudflareclient.com/v0a4471/reg` | при регистрации | кэш конфигов, `warp_verified_seeds.json` |

## Статические данные (оставлены осознанно)

| Данные | Где | Почему не динамика |
|---|---|---|
| DC-таблица и IP-префиксы Telegram | `nova-router/tg_init.go`, `assets/ip/telegram.txt` | Свойство протокола MTProto; обновляется с версией приложения, список IP дополнительно синхронизируется |
| CIDR YouTube/Google | `assets/ip/youtube.txt` | Seed; обновляется через `ListSync`, встроенная копия нужна офлайн |
| Списки доменов | `assets/lists/*` | Seed на первый запуск; сеть — через манифест |
| `proton_nodes.json` | assets | Начальный каталог серверов; живой список берётся у Proton API |
| `warp_verified_seeds.json` | assets | Проверенные seed-конфиги; актуальные — регистрация WARP и сканер |
| SNI-маски (`traffic_mask_*.sni`, `proven_*.sni`, `white.sni`) | assets | Набор для маскировки трафика, меняется вместе с релизом |
| Резолверы по умолчанию | `DnsRules.defaults()` | Адреса-семена; рантайм-состояние и замер транспорта — в `LocalDnsProxyManager` |
| Локализация | `assets/i18n/*.json` | Текст интерфейса, не данные сети |

## Правила для новых источников

1. Адрес — только в `ExternalSources`, не строкой на экране.
2. Загрузка — только через `FeedHttp` с тайм-аутами и потолком.
3. У каждого вызова — зеркало, кэш или встроенный seed.
4. Ответ проверяется до записи: JSON/формат/`sha256`, как у `ListSync`.
5. Ошибка видна в журнале и, если действие ручное, в интерфейсе.

## Обновления: важное ограничение

Релизы форка лежат в **приватном** `abonent0007/OBNOVA`. GitHub API без токена
отвечает на такой репозиторий `404`, поэтому встроенная проверка обновлений
(она и так выключена: `BuildConfig.UPDATER_ENABLED = false`) не может найти
новую версию — журнал пишет «недоступны без авторизации». Токен в APK не
кладём. Рабочие варианты: публичный репозиторий только с релизами (без
исходников), собственный публичный `apk_version.json` + APK, либо ручное
обновление из приватного репозитория.
