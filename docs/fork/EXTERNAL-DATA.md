# Внешние данные и статические запасные пути

> Инвентаризация всех источников, которые форк читает во время работы.
> Обновлено 2026-11-02. Если источник добавляется, он попадает сюда и в
> `ExternalSources.kt`.

## 1. Списки маршрутизации

| Что | Источник | Как обновляется | Запасной путь |
|---|---|---|---|
| `main.txt`, `second.txt`, `exclude.txt`, `ai.txt`, `youtube.txt`, `telegram.txt`, `whatsapp.txt`, `discord.txt`, `cloudflare.txt`, `games.txt`, `rkn.txt`, `opera_bootstrap_domains.txt` | `confeden/nova_updates`, каталог `nova_pc/list/` | Кнопка «Обновить списки»; набор файлов берётся из `manifest.json`, а не из кода | Встроенные копии в `app/src/main/assets/lists/` |
| `ip/cloudflare.txt` | тот же репозиторий | Только если файл есть в манифесте | `assets/lists/cloudflare_ips.txt` |
| Локальные TLD | `list/local_tlds.txt` (если появится в манифесте) | Вместе с остальными списками | `assets/lists/local_tlds.txt` → `RoutingPolicy.LOCAL_TLDS` |
| `manifest.json` | `nova_pc/manifest.json` | Каждая синхронизация | Нет: без манифеста обновление не начинается, остаются прежние файлы |

Зеркала: `raw.githubusercontent.com`, `cdn.jsdelivr.net`, `raw.githack.com`.
Каждый файл проверяется по sha256 из манифеста. Новые списки скачиваются во
временный каталог и заменяют прежние только целиком: смеси версий не бывает.

| Что | Источник | Как обновляется | Запасной путь |
|---|---|---|---|
| Публичная подписка | `https://iboxz.github.io/free-v2ray-collector/main/vless.txt` (тот же источник, что в `profiles/subscriptions.json` PC) | Кнопка «Загрузить публичную подписку» в «Маршрутах»; своя подписка — кнопкой «Обновить подписку» | Нет: без живой подписки MULTI остаётся на DESYNC |
| Живость узла | сам узел | Проверка SOCKS-инбаунда: HTTP до `example.com` + настоящий TLS на 443 | Узел отбраковывается, перебор идёт дальше |

Свободные узлы нестабильны: глубокая HTTPS-проба специально отсеивает узлы,
которые отдают HTTP и молча роняют TLS.

## 4. Что осталось константой осознанно

- Репозиторий и зеркала списков — это идентификатор стокового фида, а не
  пользовательские данные.
- Публичная VLESS-подписка — seed из PC-форка; пользователь может заменить её
  своей подпиской через существующий импорт.
- Порты и имена файлов протокола (`config.json`, `status.json`) — часть
  контракта между Kotlin и Go, менять их динамически нельзя.
- Облачные профили Proton/WARP/Opera не тронуты: их источники остаются
  стоковыми по правилам форка.
