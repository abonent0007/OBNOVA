Зеркала: `raw.githubusercontent.com`, `cdn.jsdelivr.net`, `raw.githack.com`.
Каждый файл проверяется по sha256 из манифеста. Новые списки скачиваются во
временный каталог и заменяют прежние только целиком: смеси версий не бывает.

Проверка 2026-11-04: в манифесте upstream только `list/*`, файлов `ip/*` там
нет, поэтому CIDR YouTube/Telegram/Cloudflare на устройстве берутся из
встроенных `assets`. Код синхронизации к их появлению готов, но «динамическими»
они станут только после публикации в фиде.

Подписки (публичная VLESS и WARP по умолчанию) остаются стоковыми:
`iboxz/free-v2ray-collector` и `confeden/auto-warp-config`. Наш публичный
репозиторий — только канал обновления APK, подписки с него не берутся.

## 5. Что осталось константой осознанно

- Репозиторий и зеркала списков — это идентификатор стокового фида, а не
  пользовательские данные.
- Публичная VLESS-подписка — seed из PC-форка; пользователь может заменить её
  своей подпиской через существующий импорт.
- Порты и имена файлов протокола (`config.json`, `status.json`) — часть
  контракта между Kotlin и Go, менять их динамически нельзя.
- Облачные профили Proton/WARP/Opera не тронуты: их источники остаются
  стоковыми по правилам форка.
- Репозиторий `abonent0007/OBNOVA` публичный (решение владельца 2026-11-04),
  поэтому обновления читаются без токена. Кнопка «Скачать последнюю версию»
  ведёт на его страницу релизов.
