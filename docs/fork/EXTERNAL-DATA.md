## 5. Что осталось константой осознанно

- Репозиторий и зеркала списков — это идентификатор стокового фида, а не
  пользовательские данные.
- Публичная VLESS-подписка — seed из PC-форка; пользователь может заменить её
  своей подпиской через существующий импорт.
- Порты и имена файлов протокола (`config.json`, `status.json`) — часть
  контракта между Kotlin и Go, менять их динамически нельзя.
- Облачные профили Proton/WARP/Opera не тронуты: их источники остаются
  стоковыми по правилам форка.
- Репозиторий `abonent0007/OBNOVA` публичный (решение владельца 2026-11-04),
  поэтому обновления читаются без токена. Кнопка «Скачать последнюю версию»
  ведёт на его страницу релизов.

## 6. Что было удалено как заглушка

- Зашитый список из девяти файлов в `ListSync`: заменён разбором манифеста.
- Вторая копия таблицы подписей маршрутов в `RoutesActivity.defaultHint`:
  заменена `RouteSettings.chainHint`.
- Обещание `RELAY` для Telegram в UI: слота relay в конфигурации нет,
  показывается фактический `PRIMARY`.
- Зашитые цели проверки сервисов: заменены выбором из списков с запасными
  хостами.
- Загрузка `ip/cloudflare.txt` и `ip/telegram.txt` из манифеста не работала:
  манифест их не публикует. Теперь они берутся из оригинального
  `confeden/Nova` и сливаются с встроенными.
- `telegram_ips.txt` больше не «мёртвое» имя: синхронизация кладёт туда
  объединение upstream и asset. `youtube_ips.txt` остаётся встроенным — файла
  в PC-репозитории нет.
- Запасная загрузка подписки в `WarpConfigsActivity` без тайм-аутов заменена
  `FeedHttp`; ошибка видна пользователю.
